# Pinterest → Яндекс.Диск (Авито-облако)

Автоматически скачивает новые фото с твоих Pinterest-досок и заливает их в
папку на Яндекс.Диске, без дублей. Работает бесплатно на GitHub Actions —
раз в день само, плюс кнопка "запустить сейчас".

## Разовая настройка (займёт минут 10-15)

### 1. Создать репозиторий на GitHub
1. Зайди на https://github.com, зарегистрируйся, если ещё нет аккаунта.
2. Нажми "New repository". Название — например `kiki-pinterest-automation`.
   Сделай его **Private** (чтобы никто чужой не видел).
3. Залей туда все файлы из этой папки (можно просто перетащить в интерфейсе
   GitHub через "Add file" → "Upload files", либо я подготовлю архив).

### 2. Получить токен Яндекс.Диска
1. Открой https://oauth.yandex.ru/
2. "Создать приложение" → название любое, например `kiki-yadisk`.
3. В разделе "Яндекс.Диск REST API" отметь права:
   - "Запись в любом месте на Диске"
   - "Чтение всего Диска"
4. Сохрани приложение, скопируй **ClientID**.
5. Перейди по ссылке (подставь свой ClientID вместо `XXXX`):
   `https://oauth.yandex.ru/authorize?response_type=token&client_id=XXXX`
6. Разреши доступ — тебя перебросит на страницу с длинной строкой после
   `#access_token=` в адресной строке. Это и есть токен. Скопируй только его
   (до знака `&`).

### 3. Добавить токен и ссылку на папку в GitHub
В репозитории: Settings → Secrets and variables → Actions.
- Вкладка **Secrets** → "New repository secret":
  имя `YADISK_TOKEN`, значение — токен из шага 2.
- Вкладка **Variables** → "New repository variable":
  имя `YADISK_ROOT_PUBLIC_URL`, значение — твоя ссылка
  `https://disk.yandex.ru/d/uA7CIQkdNlV_xQ`.

### 4. Добавить доски Pinterest
Открой `config/boards.csv`, впиши строки в формате:
```
board_url,yadisk_subfolder
https://pinterest.com/твой_ник/название-доски/,Кофейные_стойки
```
Одна строка = одна доска. `yadisk_subfolder` — как назвать подпапку внутри
Авито-облака для фото с этой доски (можно оставить пустым — тогда фото
пойдут прямо в корень). Когда появляются новые доски — просто дописываешь
новую строку, ничего больше трогать не нужно.

### 5. Запустить и проверить
В репозитории: вкладка **Actions** → "Pinterest -> Yandex Disk sync" →
"Run workflow" → зелёная кнопка "Run workflow". Через минуту-две в логах
увидишь, что скачалось, а в папке на Яндекс.Диске появятся новые фото.

После первого успешного ручного запуска дальше скрипт будет сам
срабатывать каждый день в 9:00 по Москве и подтягивать всё новое.

## Как это работает
- Реестр обработанных фото хранится в `registry.csv` прямо в репозитории —
  так дедупликация работает между запусками, ничего не задваивается.
- Имя файла на Диске = ID пина в Pinterest — гарантированно уникально.
- Если добавишь фото, которое уже было на другой доске — скрипт увидит
  совпадение по хэшу содержимого файла и не зальёт копию.
